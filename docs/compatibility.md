# 호환성 시험 결과

## 현재 완료된 환경

| 항목 | 결과 |
|---|---|
| Mac | MacBook Pro (Mac17,2), Apple M5 |
| macOS | 26.2 (25C56) |
| 아키텍처 | arm64 |
| 내장 화면 탐색 | 성공 |
| 0° → 90° → 0° | 성공 |
| 0° → 180° → 0° | 성공 |
| 0° → 270° → 0° | 성공 |
| 해상도 복구 | 1512x982 / 3024x1964 유지 |
| 주사율 복구 | 120Hz 유지 |
| 스케일링 복구 | on 유지 |
| 메뉴 막대 앱 기동 | 성공 |
| Core 자동 테스트 | 6개 통과 |
| 독립 failsafe 실행 | 성공 |
| 로컬 앱 번들 서명 검증 | 성공 |

## 구현으로 검증한 상태 변화

- 회전 전 복구 상태를 원자적으로 JSON 파일에 저장
- 회전 적용 후 Core Graphics로 목표 각도 확인
- 15초 확인 대화상자 시간 초과 시 이전 방향 복구
- 앱과 독립된 failsafe helper가 15초 후 이전 모드를 재적용
- 앱 재실행 시 미완료 복구 상태 감지 및 원복
- 잠자기 해제 후 사용자가 마지막으로 확인한 방향 복원
- 디스플레이 구성 변경 시 내장 화면 재탐색
- 긴급 0° 복구

## 추가 하드웨어가 필요한 미완료 매트릭스

- M1, M2, M3, M4 MacBook
- MacBook Air
- macOS 15 실기기
- 외장 모니터 확장 및 미러링
- 덮개 닫힘/열림과 사용자 전환
- 화면 녹화 및 전체 화면 앱 실행 중 회전

현재 환경에서 확인할 수 없는 항목은 지원 기기를 확보할 때 같은 시험 절차로 기록한다.
